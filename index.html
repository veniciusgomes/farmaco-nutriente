Consulta de interações droga–nutriente extraídas de bulas profissionais registradas na ANVISA. Digite um ou mais fármacos para ver o que a bula diz sobre alimentos, minerais, vitaminas e fibras.

Aceita nome do princípio ativo ou nome comercial. Base atual cobre 30 fármacos — veja "Sobre esta base" abaixo para o escopo completo.

Sobre esta base

Fonte: texto de bulas profissionais registradas na ANVISA (seção "Interações medicamentosas" / "Interação medicamento-alimento"), obtidas via os PDFs publicados pelos próprios fabricantes — o mesmo conteúdo aprovado e exigido pela RDC 47/2009. Não há, até o momento, uma fonte adicional (como a base DDID) integrada — os registros abaixo são 100% ANVISA.

Como foi montada: cada bula foi lida e as menções a alimentos, minerais, vitaminas e fibras foram extraídas manualmente para esta base. Nenhum dado foi inferido ou complementado com informação fora da bula.

Limitação importante: esta é uma base de teste/protótipo, ainda sem revisão por farmacêutico ou nutricionista. Trate cada registro como ponto de partida para checagem na bula original, não como recomendação clínica pronta.
